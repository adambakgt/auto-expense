# QA 체크리스트

## 주요 기능 테스트

### 1. 인증 기능
- [ ] 회원가입
  - [ ] 이메일과 비밀번호로 회원가입 가능
  - [ ] 회원가입 후 자동으로 대시보드로 이동
  - [ ] 프로필이 자동으로 생성됨
- [ ] 로그인
  - [ ] 등록된 이메일/비밀번호로 로그인 가능
  - [ ] 로그인 후 대시보드로 이동
  - [ ] 잘못된 정보 입력 시 에러 메시지 표시
- [ ] 로그아웃
  - [ ] 로그아웃 버튼 클릭 시 로그아웃됨
  - [ ] 로그아웃 후 랜딩 페이지로 이동
- [ ] 보호된 라우트
  - [ ] 로그인하지 않은 상태에서 `/dashboard` 접근 시 로그인 페이지로 리다이렉트
  - [ ] 로그인한 상태에서 `/login`, `/signup` 접근 시 대시보드로 리다이렉트

### 2. 영수증 업로드 및 AI 분석
- [ ] 영수증 이미지 업로드
  - [ ] 드래그앤드롭으로 파일 업로드 가능
  - [ ] 클릭하여 파일 선택 가능
  - [ ] JPEG, PNG, WebP 형식 파일 업로드 가능
  - [ ] 5MB 이하 파일만 업로드 가능 (초과 시 에러 메시지)
- [ ] AI 분석
  - [ ] 업로드 후 AI 분석 시작 (로딩 표시)
  - [ ] 분석 완료 후 자동으로 지출결의서 폼에 데이터 채워짐
  - [ ] 날짜, 가맹점명, 금액, 지출항목, 적요가 정확하게 추출됨
- [ ] 분석 실패 처리
  - [ ] 잘못된 이미지 업로드 시 에러 메시지 표시
  - [ ] OpenAI API 오류 시 사용자 친화적 메시지 표시

### 3. 지출결의서 관리
- [ ] 지출결의서 제출
  - [ ] AI 분석 결과 확인 후 제출 가능
  - [ ] 수동으로 필드 수정 후 제출 가능
  - [ ] 필수 필드 누락 시 제출 불가
  - [ ] 제출 성공 시 목록에 표시됨
- [ ] 지출결의서 목록
  - [ ] 대시보드에서 제출한 결의서 목록 확인 가능
  - [ ] 카드 형태로 표시됨 (가맹점명, 날짜, 금액, 상태)
  - [ ] 최신순으로 정렬됨
- [ ] 지출결의서 상세
  - [ ] 카드 클릭 시 상세 페이지로 이동
  - [ ] 모든 정보가 정확하게 표시됨
  - [ ] 영수증 이미지가 표시됨 (업로드한 경우)
- [ ] 지출결의서 수정
  - [ ] 상세 페이지에서 수정 버튼 클릭
  - [ ] 폼 수정 후 저장 가능
  - [ ] 수정 후 변경사항이 반영됨
- [ ] 지출결의서 삭제
  - [ ] 삭제 버튼 클릭 시 확인 다이얼로그 표시
  - [ ] 확인 시 삭제되고 목록에서 제거됨

### 4. 카드내역 업로드
- [ ] 파일 업로드
  - [ ] Excel (.xls, .xlsx) 파일 업로드 가능
  - [ ] CSV 파일 업로드 가능
  - [ ] 10MB 이하 파일만 업로드 가능
  - [ ] 업로드 성공 시 히스토리에 표시됨
- [ ] 업로드 히스토리
  - [ ] 업로드한 파일 목록 확인 가능
  - [ ] 파일명, 업로드 날짜, 상태 표시
  - [ ] 최신순으로 정렬됨

### 5. 대시보드 통계
- [ ] 이번 달 지출 건수
  - [ ] 현재 월의 지출 건수가 정확하게 표시됨
- [ ] 이번 달 총 지출액
  - [ ] 현재 월의 총 지출액이 정확하게 계산되어 표시됨
  - [ ] 금액 포맷팅이 올바르게 표시됨 (천 단위 구분)

## 사용자 시나리오 테스트

### 시나리오 1: 신규 사용자 회원가입 및 첫 지출결의서 제출
1. [ ] 랜딩 페이지에서 "회원가입" 클릭
2. [ ] 이름, 이메일, 비밀번호 입력 후 회원가입
3. [ ] 자동으로 대시보드로 이동
4. [ ] "영수증 업로드하기" 버튼 클릭
5. [ ] 영수증 이미지 업로드
6. [ ] AI 분석 완료 후 폼 확인
7. [ ] "제출" 버튼 클릭
8. [ ] 목록에 새 결의서가 표시됨

### 시나리오 2: 기존 사용자 로그인 및 결의서 수정
1. [ ] 로그인 페이지에서 이메일/비밀번호 입력
2. [ ] 대시보드에서 기존 결의서 클릭
3. [ ] 상세 페이지에서 "수정" 버튼 클릭
4. [ ] 금액 수정 후 저장
5. [ ] 변경사항이 반영됨

### 시나리오 3: 카드내역 업로드
1. [ ] 대시보드에서 "카드내역 업로드" 클릭
2. [ ] Excel 파일 선택
3. [ ] 업로드 완료
4. [ ] 히스토리에서 확인

## 반응형 디자인 테스트

- [ ] 데스크톱 (1920x1080)
  - [ ] 모든 요소가 올바르게 표시됨
  - [ ] 그리드 레이아웃이 정상 작동
- [ ] 태블릿 (768x1024)
  - [ ] 레이아웃이 적절하게 조정됨
  - [ ] 카드 그리드가 2열로 표시됨
- [ ] 모바일 (375x667)
  - [ ] 모든 기능이 터치로 사용 가능
  - [ ] 카드 그리드가 1열로 표시됨
  - [ ] 네비게이션이 모바일에 적합하게 표시됨

## 에러 케이스 테스트

- [ ] 네트워크 오류
  - [ ] API 호출 실패 시 에러 메시지 표시
  - [ ] 사용자가 재시도 가능
- [ ] 인증 만료
  - [ ] 세션 만료 시 자동으로 로그인 페이지로 리다이렉트
- [ ] 잘못된 파일 형식
  - [ ] 지원하지 않는 파일 형식 업로드 시 에러 메시지
- [ ] 파일 크기 초과
  - [ ] 제한 크기 초과 파일 업로드 시 에러 메시지
- [ ] OpenAI API 오류
  - [ ] API 할당량 초과 또는 오류 시 사용자 친화적 메시지

## 성능 테스트

- [ ] 페이지 로딩 속도
  - [ ] 초기 로딩이 3초 이내
  - [ ] 이미지 로딩이 적절한 속도
- [ ] AI 분석 속도
  - [ ] 영수증 분석이 10초 이내 완료
- [ ] 대량 데이터 처리
  - [ ] 100개 이상의 결의서 목록도 부드럽게 표시
