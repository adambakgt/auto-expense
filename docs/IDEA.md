## 📌 핵심 Pain Point 정의 (직원 + 담당자 중심)

👤 1) 직원 페인포인트 — “지출결의서 쓰는 것 자체가 고역”

직원은 아래 이유로 지출결의서를 쓰는 것을 가장 귀찮아함.

직원이 느끼는 실제 고통
• 영수증 사진 찍고,
• 날짜/금액/가맹점/항목 하나씩 입력하고,
• 적요까지 작성해야 해서 손이 너무 많이 감
• 출장 등으로 쌓아두면 한 번에 몰아서 해야 해서 스트레스
• 카드 자동결제(구독, 클라우드 비용 등)는 영수증이 없어 더 헷갈림
• “이걸 내가 왜 적어야 하지…” 하는 감정적 피로

직원은 “지출결의서 작업 = 내 본업과 전혀 관계없는 귀찮은 의무”라고 느낀다.

🧑‍💼 2) 경영관리 담당자 페인포인트 — ‘누락건 찾기’의 지옥

담당자는 직원보다 더 고통 받는다.

담당자가 느끼는 실제 고통
• 직원이 제출 안 한 영수증이 무엇인지 ‘수동으로 찾아야’ 함
• 카드내역 vs 영수증 제출건 비교가 매월 반복되는 지옥
• 자동결제건(구독료·SaaS·통신비·API 사용료 등)은
영수증이 없으니 직원이 무엇을 써야 하는지 몰라서 누락 대량 발생
• 누락건은 결국 담당자가 직접 직원에게 하나하나 재촉해야 함
• 결제 건수 많은 팀은 누락이 더 많아 파악 불가 수준
• 미제출 건 때문에 세무사로부터 “증빙 달라”는 연락 수시로 옴

담당자는 “누락건 찾는 데 하루가 날아간다”고 말한다.

## 🎯 해결해야 할 문제 핵심 요약

👉 직원은 ‘작성 자체가 귀찮아서 제출을 미룸’ → 누락 증가
👉 담당자는 ‘누락된 건을 사람이 찾는 구조’ → 반복적 노동, 오류 증가

➡️ 두 Pain Point 모두 해결해야 진짜 가치가 발생한다.

## 💡 AI 솔루션의 핵심 해결 전략 (Pain 중심 버전)

✔️ 1) 직원: 지출결의서 자동 생성 (작성 부담 90% 제거)

직원이 지출결의서를 작성하지 않도록 구조 자체를 바꾼다.

해결 방식
• 직원은 단지 영수증 사진 1장 업로드
• AI가 자동으로
• 날짜
• 금액
• 가맹점
• 지출항목
• 적요
• 계정과목
을 모두 채운 완성된 지출결의서를 만들어줌
• 직원은 “확인 → 제출”만 클릭

즉, 직원이 입력하는 것은 0~1개.
작성의 90%를 없앤다.

✔️ 2) 담당자: 자동 누락 탐지 기능 (Missing Detection)

카드내역, 결제내역, 자동결제건을 AI가 분석해
‘제출된 결의서 + 제출되지 않은 결제건’을 자동으로 리스트업한다.

해결 방식
• 매월 카드 승인내역 Excel 업로드
• AI가 세 가지 비교를 동시에 수행 1. 카드내역 vs 제출된 영수증 2. 제출된 영수증 vs 자동결제 정기 지출 3. 반복 가맹점 패턴 분석으로 결제건 누락 탐지
• 누락된 건은 자동으로 직원에게 메시지
“5월 ○○일 지출 건이 아직 제출되지 않았습니다”
• 자동결제건은 AI가 “이 비용은 자동결제건으로 파악됨”이라고 태그 추가

→ 담당자는 ‘누락 탐지 로직’만 보면 되고,
일일이 찾지 않아도 된다.

## 🏆 핵심 가치 (문제 해결 중심)

직원에게는

“지출결의서 쓰는 시간이 10분 → 10초로 줄어든다.”
→ 귀찮음 해결
→ 제출률 증가
→ 담당자가 재촉할 필요 없어짐

담당자에게는

“누락건 찾는 데 하루 걸리던 작업이 1초로 끝난다.”
→ 자동 매칭 / 자동 결측 탐지
→ 자동결제건까지 분류
→ 세무사 오류 대응 감소

회사 전체에는

“경영관리 불필요 노동 50~70% 절감, 누락 80% 감소”

## 📄 지출결의서 중심 MVP 요약 (Pain 중심으로 재구성)

👉 직원 Pain 해결
• 영수증 찍기 → AI가 결의서 자동생성
• 직원은 “확인 → 제출”만
• 자동결제건도 AI가 설명 텍스트 생성
(예: “Notion 월 8달러 자동결제건입니다”)

👉 담당자 Pain 해결
• 카드내역 vs 제출건 자동 매칭
• 누락건 자동 리스트업
• 직원에게 자동 알림
• 자동결제 패턴 자동 식별

→ ‘입력 노동 제거 + 누락 탐지 자동화’가 이 서비스의 정수
